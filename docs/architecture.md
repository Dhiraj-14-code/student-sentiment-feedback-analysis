# Architecture
The application uses a Client-Server architecture.

## Frontend
- React.js single-page application.
- State managed by React hooks.
- Routes handled via react-router-dom.
- UI styling with Tailwind CSS.
- Charts generated with Recharts.

## Backend
- REST API built with FastAPI.
- Uses SQLAlchemy as ORM.
- Authentication via JWT.
- NLP module uses vaderSentiment for lightweight and accurate sentiment scoring.
